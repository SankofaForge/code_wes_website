# Marks

Line drawings made in Glaxnimate for the resources page. Each SVG is the source; the site inlines the same paths so GSAP can draw them on, and swaps the hex colors for the site's tokens.

| File | Used in |
| --- | --- |
| `campus.svg` | the Campus folder on `/resources/` (`src/components/FolderArt.tsx`) |
| `careers.svg` | the Careers folder |
| `learning.svg` | the Learning folder |
| `glyphs.svg` | the marks beside resource links with no brand logo (`src/data/resource-icons.ts`) |

The Courses folder has no file here: it draws the real course map, small, from `content/courses/`.

Brand logos beside other links (Python, freeCodeCamp, Khan Academy, MDN, JavaScript, Handshake, GitHub, LinkedIn) come from [Simple Icons](https://simpleicons.org/) (CC0). The marks themselves belong to their owners.
